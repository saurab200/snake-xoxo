# Medusa — presentation screenshots

Captured from the release APK on `emulator-5554` (Pixel, 1080x2400, full resolution, uncropped).
Signed in throughout as **Jyoti Tiwari** (`jtq19@txstate.edu`), 80 pts, Level 4, Blue skin active.

Numbered in **demo order** — walk the deck top to bottom and the product tells its own story:
sign in → see your standing → start a session → work the tasks → watch the distractions vanish → collect the reward.
